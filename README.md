# Curso Angular - Módulo 1

Proyectos del curso **Desarrollo de páginas con Angular** (Coursera).

## Proyectos

- **angular-hola-mundo**: primera aplicación Angular, con un componente propio y Bootstrap.
- **angular-wishlist**: lista de destinos de viaje. Permite agregar destinos con nombre e imagen y los muestra como tarjetas.

## Conceptos aplicados

- Componentes y estructura de una app Angular
- Enlace de datos (`{{ }}`, `[propiedad]`, `(evento)`)
- Variables de plantilla con `#`
- `@Input` para pasar datos entre componentes
- `@HostBinding` para asignar clases CSS al componente
- Directiva `*ngFor` para listar elementos
- Modelo de dominio en TypeScript
- Bootstrap para el diseño

## Cómo ejecutarlo

Requisitos: Node.js y Angular CLI.

```
cd angular-wishlist
npm install
ng serve
```

Luego abre `http://localhost:4200`.
